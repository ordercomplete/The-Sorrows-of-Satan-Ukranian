# 🎬 Сценарій фільму за романом «Смуток Сатани» (The Sorrows of Satan, Марі Кореллі, 1895)

Друге призначення додатка. Джерело сюжету — `../Text-origin/chapters/*.txt` (38 глав, ~947K символів), українські формулювання — `../output/translated/chapter_*_ukr.md`, стиль діалогів — `../docs/translation_template.md`.

## Структура (план)

- `synopsis.md` — синопсис: логлайн, теми, арка Джеффрі Темпеста.
- `characters.md` — персонажі: роль, мета, арка, ключові сцени.
- `scenes/` — сцени по главах (`scene_I.md`, ...): місце, час, дійові особи, діалог, ремарки.
- `adaptation-notes.md` — що змінено відносно роману і чому.

## Статус
