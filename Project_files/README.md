# The-Sorrows-of-Satan-Ukranian

Переклад роману Марі Кореллі «The Sorrows of Satan» (Project Gutenberg, 1895) українською + сценарій фільму за романом. Додатково — розпізнавання рукописного тексту (AI-reading).

- `PLAN.md` — план і статус (три призначення).
- `START_HERE.md` — з чого почати.
- `Text-origin/` — оригінал (Gutenberg PDF + `chapters/chapter_*.txt`).
- `output/translated/` — переклади глав (`chapter_*_ukr.md`, шаблон `docs/translation_template.md`).
- `screenplay/` — сценарій (друге призначення).
- `archive/ocr-legacy/` — спадок рукописного OCR-етапу (додаткова функція).
- `src/` — скрипти (`translate/`, `ocr/`).
- `docs/` — `book_structure.md` (38 глав, прогрес), шаблони.
