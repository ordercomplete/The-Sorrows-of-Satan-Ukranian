# Архів OCR-спадку (рукописний етап RU→UK)

Додаткова функція додатка. Сюди переїхало все, що стосується розпізнавання рукописних сторінок і не належить до перекладу Гутенберга:

- `input/*.jpg` — фото рукописних сторінок (російська, синя ручка).
- `output/recognized/*.txt` — результати AI-reading.
- `src/ocr/*` — EasyOCR / TROCR скрипти (зафіксовано як непрацюючі, еталон — прямий AI-reading, див. `../REFERENCE_METHOD.md`).
- `REFERENCE_METHOD.md`, `ocr_model_analysis.md`, `PLAN_400_ERROR.md` — доки етапу.

Переміщення архіву — наступний крок реорганізації (поки лишено на місцях, щоб не ламати відносні шляхи в `src/*.py`).
