# План усунення 400 API Payload Error

## Проблема
Кожна спроба обробки `d:\GEN\Text-OCR\input\002-003_pages.jpg` завершується з помилкою:
```
Request Failed: 400
{"error":"Invalid 'messages' in payload. Please check the structure of your 'messages' and try again."}
```

## Аналіз причини
1. `view_image` успішно завантажує зображення — проблема не в файлі
2. Помилка виникає при **подальшій обробці** (запит до API)
3. Ймовірна причина: структура messages не валідується для великого контексту

## Варіанти вирішення (від найпростішого)

### Варіант 1: Розділити зображення на сторінки
**Мета:** Зменшити розмір кожного запиту
```
1. Розрізати 002-003_pages.jpg на дві частини (ліва/права колонки)
2. Обробити кожну частину окремо
3. Об'єднати результати
```
**Переваги:** Зменшує контекстне вікно, простіше реалізувати
**Недоліки:** Потрібен додатковий інструмент для розрізання

### Варіант 2: Використати base64 замість file path
**Мета:** Змінити формат передачі зображення
```
1. Конвертувати зображення в base64
2. Передати через data URI в payload
```
**Переваги:** Можливо обійде валідацію
**Недоліки:** Збільшує розмір запиту

### Варіант 3: Змінити структуру messages
**Мета:** Виправити формат запиту
```
1. Додати explicit system prompt
2. Змінити порядок messages
3. Використати інший формат опису зображення
```
**Переваги:** Можливо знайти правильну структуру
**Недоліки:** Потрібне тестування

### Варіант 4: Fallback — описати текст вручну
**Мета:** Отримати текст без API
```
1. Використати вже завантажений контекст зображення
2. Безпосередньо описати видимий текст
3. Зберегти в output/recognized/
```
**Переваги:** Не потребує API викликів
**Недоліки:** Може бути неточно для дрібного тексту

## Рекомендований порядок
1. **Спробувати Варіант 1** — розділити зображення
2. Якщо не працює → **Варіант 3** — змінити структуру messages
3. Якщо не працює → **Варіант 4** — fallback опис

## Критерії успіху
- [ ] Помилка 400 зникає
- [ ] Текст розпізнається точно
- [ ] Результат зберігається в `output/recognized/002-003_pages_etalon.txt`

## Попередні інсайти
- Hallucination була при прямому описі — потрібна валідація
- Традиційний OCR pipeline не працює (HTTP 400)
- `view_image` працює — зображення доступне в контексті
