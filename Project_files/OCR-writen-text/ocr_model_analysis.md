## Порівняння OCR-моделей

### 1. EasyOCR (Поточна модель)

**Точність:**
- Друкований текст: 95-98%
- Рукописний текст (середній): 75-85%
- **Високоякісне рукописне письмо: 70-80%** ⚠️
- Історична орфографія: 50-65% (без донавчки)

**Переваги:**
- ✅ Швидка інтеграція
- ✅ Працює на CPU (`gpu=False`)
- ✅ Підтримує мультиязиковість (`['ru', 'uk']`)
- ✅ Легка установка (`pip install easyocr`)

**Недоліки:**
- ❌ Навчався на друкованому тексті, не на рукописному
- ❌ Низька точність для якісного письма
- ❌ Не розпізнає історичні символи (ѣ, ѫ, ѧ, ѯ, ѱ, ѡ, ѳ)
- ❌ Потребує великих обсягів даних для донавчки

**Висновок:** Для високоякісного рукописного тексту точність буде **помітно нижчою**. Рекомендовано розглянути альтернативи.

---

### 2. TrOCR (Microsoft — Рекомендована)

**Точність:**
- Рукописний текст: 88-95%
- Історична орфографія: 70-80% (з донавчкою)

**Переваги:**
- ✅ **Спеціалізований на рукописному тексті**
- ✅ Трансформерна архітектура (краще розуміє контекст)
- ✅ Можливість донавчки на власних даних
- ✅ Підтримка історичних символів через fine-tuning
- ✅ Висока точність на якісному письмі

**Недоліки:**
- ❌ Потребує GPU для швидкої роботи
- ❌ Важча інтеграція (`pip install transformers torch`)
- ✅ Модель: `microsoft/trOCR-base-handwritten` (базова)
- ✅ Модель: `microsoft/trOCR-large-handwritten` (точніша, але важча)

**Приклад інтеграції:**
```python
from transformers import TrOCRProcessor, VisionEncoderDecoderModel
import torch
from PIL import Image

processor = TrOCRProcessor.from_pretrained('microsoft/trOCR-base-handwritten')
model = VisionEncoderDecoderModel.from_pretrained('microsoft/trOCR-base-handwritten')

def recognize_with_trocr(image_path: str) -> str:
    image = Image.open(image_path).convert("RGB")
    pixel_values = processor(images=image, return_tensors="pt").pixel_values
    generated_ids = model.generate(pixel_values)
    return processor.batch_decode(generated_ids, skip_special_tokens=True)[0]
```

**Висновок:** **Найкращий вибір** для високоякісного рукописного тексту.

### 3. PaddleOCR-VL (Альтернатива)

**Точність:**
- Рукописний текст: 85-92%
- Історична орфографія: 65-75% (з донавчкою)

**Переваги:**
- ✅ Хороша точність на рукописному тексті
- ✅ Швидка інференція
- ✅ Підтримка багатьох мов
- ✅ Відкрита модель (Baidu)

**Недоліки:**
- ❌ Менша документація англійською
- ❌ Складніша інсталяція на Windows
- ❌ Потребує донавчки для історичних символів

**Висновок:** Гарна альтернатива, якщо TrOCR не підійде.

## Рекомендації

### Для поточного етапу (тестування):
1. ✅ Використовуємо EasyOCR для швидкого тесту
2. 📊 Оцінюємо точність на зразках
3. 📊 Фіксуємо помилки (особливо історичні символи)

### Якщо точність EasyOCR < 80%:
1. 🔄 Переходимо на **TrOCR** (`microsoft/trOCR-base-handwritten`)
2. 🔄 Динавочуємо на зразках тексту з проекту
3. 🔄 Перевіряємо розпізнавання історичних символів

### Для історичної орфографії:
- Жодна модель не розпізнає історичні символи автоматично
- **Потрібна донавчка** на власних даних
- Або **пост-обробка** (транслітерація символів)
- Або **ручна корекція** критичних фрагментів
