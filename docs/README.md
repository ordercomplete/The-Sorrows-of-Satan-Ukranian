# 📖 Печаль сатани

## Опис проєкту
Оцифровка та переклад рукописного тексту російською мовою українською.

## Структура
- `PLAN.md` — план проєкту
- `src/` — скрипти обробки
- `input/` — вхідні зображення
- `output/` — результати
- `memories/` — журнали та історія
