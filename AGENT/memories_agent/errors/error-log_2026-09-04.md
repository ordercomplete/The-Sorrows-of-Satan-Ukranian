# Помилка: INIT-GATE порушено в чаті, де правило було доставлено
**Час:** 21:38–21:45
**Додаток/модель:** Cline, модель онлайн
**Симптом:** На перше «Привіт» агент відповів вітанням без tool call, хоча правило
`.clinerules/agent-startup.md` з hard-gate директивою БУЛО в системному промпті
(фікс v1.4.5 спрацював — правило доставлено).
**Причини:**
1. Конфлікт інструкцій у системному промпті: правило «simple question → answer directly
   without tools» перебило INIT-GATE. Модель розставила пріоритет неправильно.
2. Немає механічного гейту: Cline не виконує JSON-хуки, anti_loop.py з is_initialized()
   не запускається — нічого фізично не блокує відповідь до читання інструкцій.
3. Нечіткість формулювання: «перед будь-якими іншими діями» інтерпретовано як
   «перед робочими діями», привітання робочою дією не вважалось.
**Виправлення:** читання виконано після вказівки користувача; сесію продовжено
(файл сесії існував з 12:11, повторна ініціалізація не потрібна).
**Застосований фікс:** у канонічній інструкції та шаблоні stub-ів
(AGENT/templates/stub_agents.md) додано явний рядок: гейт має вищий пріоритет
за правило «відповідати без tool call'ів»; перше повідомлення ЛЮБОГО типу
(включно з привітанням) починається з read_files канонічного файлу.
