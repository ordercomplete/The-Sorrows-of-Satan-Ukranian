## 🔄 Правила використання — повна відповідь

### Внутрішні історії агента → memories_agent/session/, memories_agent/errors/, memories_agent/actions/
Кожен новий запис має поточний час, отриманий за шаблоном:
`python -c "from datetime import datetime; print(datetime.now().strftime('%Y-%m-%d %H:%M'))"`

### Загальні процеси проекту → залишаються в memories/
Файли `memories/session/`, `memories/errors/`, `memories/repo/action-log_` використовуються для загальних процесів проекту memories.

### Крос-референси → memories_agent/cross-reference/external-links.md
Коли агент створює записи, пов'язані із загальними процесами проєкту (не тільки внутрішні), додавати посилання в цей файл.

---

## 📌 Важливо — повна відповідь

- **Новий запис завжди додається обов'язково в кінець файлу** — не в середину і не на початок
- Кожен запис повинен мати поточний час, отриманий за шаблоном
- Фіксувати проблеми та вирішення питань самого агента
- Перевіряти всі місця де можуть бути скрипти/плагіни перед створенням нових записів
