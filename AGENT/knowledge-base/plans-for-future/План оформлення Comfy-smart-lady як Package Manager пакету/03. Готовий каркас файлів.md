### Що вже працює

| Файл | Що вміє |
|------|---------|
| `pyproject.toml` | Готовий до `pip install -e .`, entry points `csl-agent` і `comfy-smart-lady` |
| `cli.py` | Команди: `install`, `update`, `status`, `doctor`, `version` + `--dry-run` / `--force` |
| `paths.py` | Визначає source з package data → env → явного шляху |
| `engine.py` | `run_sync()` з dry-run, `SyncResult`, завантаження manifest (з JSONC), legacy argparse |
