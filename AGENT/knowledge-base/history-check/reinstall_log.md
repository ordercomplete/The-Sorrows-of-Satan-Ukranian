## Непередбачувані події та відхилення

### 1. sync-agent.py remove — файли переносяться до корзини, а не видаляються
- **Очікувалось:** Файли Агента видаляються остаточно
- **Реальність:** Команда `sync-agent.py remove` переносить файли до `AGENT/trash/` (для файлів Агента) або `trash/` (для проєктних), а не видаляє їх остаточно. Це поведінка скрипта за замовчуванням.
- **Вплив:** Для чистої установки це не критично, оскільки `--apply` під час синхронізації перезаписує файли поверх існуючих.

### 2. install.ps1 сам потрапив до корзини при видаленні
- **Очікувалось:** `install.ps1` доступний для запуску після видалення
- **Реальність:** Скрипт `agent_config/scripts/install.ps1` було перенесено до `AGENT/trash/` командою `sync-agent.py remove`, оскільки він вважався файлом Агента.
- **Рішення:** Використано `sync-agent.py --source <репо> --target . --apply` як альтернативу.

### 3. sync-agent.py --pull не працює без попереднього клонування
- **Очікувалось:** Команда `--pull` автоматично клонує репо
- **Реальність:** `--pull` шукає репо за замовчуванням у `~/repos/Comfy-smart-lady-agent/` — якщо його там немає, команда падає з помилкою "Не знайдено manifest.json".
- **Рішення:** Ручне клонування через `git clone --depth 1` у тимчасову папку, потім запуск з явним `--source`.

### 4. 4 модифіковані файли пропущено при першому видаленні
- **Очікувалось:** `sync-agent.py remove` видалить всі файли
- **Реальність:** 4 файли з модифікаціями були пропущені (Skipped: 4 files (modified)). Потрібен `--force` для видалення модифікованих.
- **Примітка:** Після першого `remove` лок-файл видаляється, тому повторний `remove --force` нічого не робить ("No agent-lock.json found").

### 5. Помилка AI-шлюзу (не пов'язана з установкою)
- Під час роботи з'являлась помилка: `Failed to create stream: inference request failed: failed to generate stream from Vercel: failed to invoke model 'private/longcat-2.0'`
- **Вплив:** Не вплинуло на процес установки (тимчасова проблема мережі/API).
