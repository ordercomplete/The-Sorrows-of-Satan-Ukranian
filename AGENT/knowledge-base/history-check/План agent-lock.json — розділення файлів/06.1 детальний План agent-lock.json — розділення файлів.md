## План: Інтеграція agent-lock.json з update-manifest.py

### Поточний потік даних

```
update-manifest.py → manifest.json → sync-agent.py → проєкт
     (сканує AGENT/)      (копіє файли)    (встановлення)
```

### Потрібний потік

```
update-manifest.py → manifest.json → sync-agent.py → проєкт
     (сканує AGENT/)      (копіє файли)    (встановлення)
                                            ↓
                                      agent-lock.json
                                      (трекінг файлів)
```

### Що робить кожен скрипт

| Скрипт | Відповідальність |
|--------|------------------|
| `update-manifest.py` | Сканує `AGENT/` → генерує `manifest.json` |
| `sync-agent.py` | Читає `manifest.json` → копіє файли → генерує `agent-lock.json` |
| `agent-lock.json` | Трекає які файли встановлені, з яким хешем та версією |

### Структура agent-lock.json (оновлена)

```json
{
  "version": "1.3.0",
  "manifest_hash": "abc123...",
  "installed_at": "2026-08-29T10:30:00",
  "files": {
    "AGENT/agents/Comfy-smart-lady.md": {
      "hash": "d4e5f6...",
      "action": "stub",
      "targets": [".github/copilot-instructions.md"],
      "installed_at": "2026-08-29T10:30:00"
    },
    ".github/hooks/anti_loop.py": {
      "hash": "a1b2c3...",
      "action": "copy_full",
      "targets": [".github/hooks/anti_loop.py"],
      "installed_at": "2026-08-29T10:30:00"
    }
  }
}
```

Ключове поле — `manifest_hash`: хеш самого `manifest.json` на момент встановлення. Це дозволяє виявити що manifest змінився (нові файли додані через `update-manifest.py`).

### Команда `status` — логіка

```
1. Зчитати agent-lock.json
2. Зчитати поточний manifest.json
3. Порівняти manifest_hash:
   - Співпадає → перевірити хеші файлів
   - Відрізняється → є нові файли в manifest!
4. Для кожного файлу:
   - В lock є, хеш співпадає → ✅ OK
   - В lock є, хеш інший → ⚠️ Modified
   - В lock є, файл відсутній → ❌ Missing
   - В manifest є, в lock нема → 🆕 New (не встановлено)
```

**Приклад виводу:**

```
📊 Стан Агента (v1.3.0):
   
   Файли:
   ✅ OK:        75 файлів
   ⚠️  Modified:   3 файли
   ❌ Missing:    2 файли
   🆕 New:        4 файли (є в manifest, не встановлені)
   
   💡 Запусти `sync-agent.py --apply` щоб встановити нові файли
   💡 Запусти `sync-agent.py status --verbose` для деталей
```

### Команда `update` — логіка

```
1. Зчитати agent-lock.json (якщо є)
2. Зчитати manifest.json
3. Виявити нові файли (є в manifest, нема в lock)
4. Виявити видалені файли (є в lock, нема в manifest)
5. Зкопіювати нові файли
6. Оновити agent-lock.json (додати нові, прибрати видалені)
7. Оновити .gitignore
```

### Команда `remove` — логіка

```
1. Зчитати agent-lock.json
2. Для кожного файлу:
   - Файл змінений (хеш інший) → пропустити (може містити ваші правки)
   - Файл не змінений → видалити
3. Прибрати шляхи Агента з .gitignore
4. Видалити agent-lock.json
```

### Зміни в скриптах

**`sync-agent.py`:**
- Додати `AgentLockManager` клас
- Додати команди `status`, `remove`, `gitignore`
- Модифікувати `main()` — генерація lock після install/update
- Додати `manifest_hash` в lock

**`update-manifest.py`:**
- Без змін (він генерує manifest)
- Але можна додати виклик `sync-agent.py --apply` після `--apply` (опціонально)

### Порядок виконання

| # | Дія | Файл |
|---|-----|------|
| 1 | Додати `AgentLockManager` клас | `sync-agent.py` |
| 2 | Додати `cmd_status()` функцію | `sync-agent.py` |
| 3 | Додати `cmd_remove()` функцію | `sync-agent.py` |
| 4 | Додати `cmd_gitignore()` функцію | `sync-agent.py` |
| 5 | Модифікувати `main()` — lock після install | `sync-agent.py` |
| 6 | Додати CLI-аргументи для нових команд | `sync-agent.py` |
| 7 | Протестувати весь цикл | — |

### Тестовий сценарій

```bash
# 1. Додали новий файл в AGENT/
echo "test" > AGENT/scripts/new_hook.py

# 2. Оновили manifest
python agent_config/scripts/update-manifest.py --apply

# 3. Встановили в проєкт
python agent_config/scripts/sync-agent.py --source . --target . --apply

# 4. Перевірили стан
python agent_config/scripts/sync-agent.py status
# Очікувано: ✅ OK: 80 файлів (включаючи новий)

# 5. Видалили Агента
python agent_config/scripts/sync-agent.py remove
# Очікувано: Видалено 80 файлів
```
