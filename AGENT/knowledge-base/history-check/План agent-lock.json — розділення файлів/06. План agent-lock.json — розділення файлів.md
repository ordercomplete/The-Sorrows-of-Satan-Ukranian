# План: agent-lock.json — розділення файлів Агента та проєкту

## Мета
Після встановлення Агента в проєкт — чітко розділити файли Агента та файли проєкту.

## Компоненти

### 1. AgentLockManager (новий клас в sync-agent.py)
- Файл: `agent-lock.json` в корені проєкту
- Містить: версію Агента, хеш manifest.json, список файлів з хешами
- Методи: load, save, add_file, get_installed_files, is_agent_file

### 2. Нові команди sync-agent.py
- `status` — показує стан встановлених файлів (OK/Modified/Missing/New)
- `remove` — видаляє тільки файли Агента (за lock-файлом)
- `gitignore` — додає шляхи Агента в .gitignore проєкту

### 3. Інтеграція з update-manifest.py
- update-manifest.py генерє manifest.json (без змін)
- sync-agent.py після install/update генерує agent-lock.json
- agent-lock.json містить manifest_hash для виявлення нових файлів

## Структура agent-lock.json

```json
{
  "version": "1.3.0",
  "manifest_hash": "abc123...",
  "installed_at": "2026-08-29T10:30:00",
  "files": {
    "AGENT/agents/Comfy-smart-lady.md": {
      "hash": "d4e5f6...",
      "action": "stub",
      "targets": [".github/copilot-instructions.md"],
      "installed_at": "2026-08-29T10:30:00"
    }
  }
}
```
