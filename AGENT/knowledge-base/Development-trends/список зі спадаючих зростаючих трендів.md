**Спадаючі тренди (втрачають актуальність / підтримку)**

- **Create React App (CRA)**  
  Офіційно deprecated з лютого 2025. Більше не отримує активної підтримки та нових фіч. React-команда прямо рекомендує переходити на фреймворки або сучасні білдери. Використовувати для нових проєктів — втрата часу.

- **Webpack як основний інструмент для нових проєктів**  
  Повільний cold start і HMR порівняно з Vite/Rspack/Turbopack. Залишається в великих legacy-кодових базах, але для всього нового його майже не обирають.

- **Чисто client-side React без meta-framework**  
  React-команда більше не рекомендує «збирати самому» з CRA + React Router + ручним data-fetching. Такий підхід створює проблеми з routing, code-splitting, waterfalls і SEO.

- **Gatsby (для більшості випадків)**  
  Сильно втратив популярність. Для контентних сайтів майже завжди краще Astro з islands architecture.

- **Класичні CSS-фреймворки (Bootstrap, Bulma тощо) як основний підхід**  
  Уступають місце Tailwind CSS + сучасним можливостям CSS (container queries, cascade layers, view transitions). Важкі framework-стилі стають зайвими.

- **Remix v2**  
  Досяг End-of-Life у 2026. Багато функціоналу перейшло в React Router v7+, а Remix 3 ще не в production-ready стані.

- **Важкі client-only бандли без SSR/SSG/RSC**  
  Підхід «все в браузері» програє server-first архітектурі за швидкістю першого завантаження та SEO.

- **Snowpack та подібні старі ESM-бандлери**  
  Давно deprecated, спільнота перейшла на Vite.

**Зростаючі тренди (набирають обертів)**

- **Meta-frameworks (Next.js, TanStack Start, Astro, SvelteKit)**  
  Стали дефолтним способом старту проєкту. Дають routing, data-fetching, code-splitting і SSR/SSG «з коробки». Next.js залишається найпопулярнішим вибором завдяки екосистемі та hiring pool.

- **Vite + сучасні білдери (Rsbuild, Rspack, Turbopack)**  
  Швидкий dev-сервер, миттєвий HMR і сучасна архітектура. Vite став стандартом для SPA та кастомних сетапів після смерті CRA.

- **React Server Components + server-first підхід**  
  Менше JavaScript у клієнті, кращий перший рендер і SEO. React Compiler додатково зменшує потребу в ручній оптимізації.

- **TypeScript як обов’язковий стандарт**  
  Частка проєктів, де пишуть виключно TypeScript, продовжує зростати. End-to-end type safety (разом з tRPC, TanStack, Zod) стає нормою.

- **TanStack-екосистема (Router, Query, Start)**  
  Швидко набирає популярність як type-safe і гнучка альтернатива Next.js, особливо для SPA та hybrid-додатків з вільним деплоєм.

- **Astro (islands architecture)**  
  Ідеальний вибір для контентних, маркетингових і документаційних сайтів. Відправляє мінімум JS і дозволяє використовувати React/Vue/Svelte лише там, де потрібно.

- **AI-assisted development (Cursor, Claude, Copilot, v0 тощо)**  
  Вже не хайп, а стандартний інструмент. Розробник все більше працює як архітектор і рев’юер, а не як той, хто пише кожен рядок вручну.

- **Edge computing (Cloudflare Workers, Vercel Edge тощо)**  
  Код виконується ближче до користувача. Низька latency і краща масштабованість стають доступними без складної інфраструктури.

- **Svelte 5 (runes) + SvelteKit та SolidStart**  
  Висока продуктивність і простий DX. Зростають у нішах, де важливий розмір бандла та швидкість, хоча екосистема менша за React.

- **Tailwind CSS + сучасний CSS**  
  Utility-first підхід домінує. Разом з нативними можливостями CSS зменшує потребу в складних CSS-in-JS рішеннях.

Ці списки відображають стан на 2026 рік: екосистема стабілізувалася, менше «вбивць React», більше фокусу на зрілості інструментів, продуктивності та AI.
