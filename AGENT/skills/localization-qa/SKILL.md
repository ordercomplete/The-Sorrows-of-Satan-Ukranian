Коли просять перевірити локалізацію:

1. Знайди файли в locales/uk/ (або вказаній папці).
2. Шукай: порожні рядки, "NIL", кракозябри, змішану мову, неперекладені ключі.
3. Виводь тільки список проблем у форматі: файл → ключ → проблема.
4. Нічого не виправляй, поки тебе прямо не попросять.

### Приклад виводу

```markdown
settings.json → VHS.AdvancedPreviews → tooltip порожній
main.json → menu.file → не перекладено (англ.)
nodeDefs.json → KSampler.title → змішана мова
```

## Анти-цикл та контекст

Детальні правила: `AGENT/skills/context-management/SKILL.md`

- 3+ однакові tool call'и — зупинитися і зробити висновок.
- При 70% заповнення — оновити `memories/session/`.
- Критичні цикли фіксувати в `memories/errors/error-log.md`.
