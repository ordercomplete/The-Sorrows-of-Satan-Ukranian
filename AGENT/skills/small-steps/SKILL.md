## Адаптивний підхід до кроків

**Прості задачі** (один файл, очевидна зміна) — дій без зайвих дрібних кроків.
**Складні задачі** (декілька файлів, незрозуміла структура) — розбивай на маленькі кроки.

### Для складних задач

- Один крок = одна дія (read/edit/verify).
- Перед дією коротко скажи, що робиш і чому.
- Подивись результат — тільки потім наступний крок.
- Якщо крок не спрацював — запиши причину і спробуй інший підхід.

### Для простих задач

- Прочитала → відредагувала → перевірила = один цикл.
- Без зайвих "скажи одним реченням, що зробиш".
