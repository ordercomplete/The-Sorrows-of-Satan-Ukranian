## 🔧 Опис функціоналу

**Cline** (раніше — Claude Dev) — автономний coding-агент прямо в IDE (VS Code), який вміє:

- ✅ **Створювати та редагувати файли** — з дозволу користувача на кожному кроці
- ✅ **Виконувати команди** в терміналі (запуск серверів, тестів, скриптів)
- ✅ **Використовувати браузер** для тестування та візуальної верифікації
- ✅ **Працювати з різними LLM** — Anthropic Claude, OpenAI, Gemini, локальні моделі (Ollama, LM Studio) тощо
- ✅ **Розуміти контекст проєкту** — читання файлів, пошук, структура коду
- ✅ **Підтримувати правила проєкту** — через `.clinerules/` (власна система правил агента)
- ✅ **Автономний режим** — може виконувати довгі багатокрокові задачі з перевіркою на кожному кроці
- ✅ **SDK та CLI** — працює як бібліотека або командний інструмент ("Autonomous coding agent as an SDK, IDE extension, or CLI assistant")

## 🎯 Переваги

- ⭐ **Найкращий автономний агент в IDE** — одна з найпопулярніших альтернатив GitHub Copilot
- 🌐 **Підтримка локальних моделей** — безкоштовна робота з Ollama/LM Studio
- 🔐 **Контроль на кожному кроці** — користувач завжди бачить, що робить агент
- 🔧 **Гнучке налаштування** — `.clinerules/` дозволяє тонко налаштувати поведінку
- ⚡ **Інтеграція з браузером** — агент може тестувати веб-застосунки

## ⚠️ Недоліки

- ⚠️ **Велике споживання токенів** — автономні задачі швидко витрачають контекст
- ⚠️ **Залежність від API-ключів** — топові моделі потребують оплати
- ⚠️ **Швидкий розвиток** — часті оновлення API можуть ламати скрипти/плагіни
- ⚠️ **Немає вбудованої синхронізації** — потрібні окремі скрипти (як `sync-agent.py`)

## 🤝 Інтеграція з агентом Comfy-smart-lady

У проєкті Cline використовує каталог **`.clinerules/`**:

- `.clinerules/knowledge-base/` — база знань
