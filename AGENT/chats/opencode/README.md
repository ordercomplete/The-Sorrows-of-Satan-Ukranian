## 🔧 Опис функціоналу

**OpenCode** — open-source coding-агент, який працює в терміналі (CLI). Раніше відомий як `sst/opencode`, зараз розвивається в організації **anomalyco**.

- ✅ **Автономне виконання задач** — агент аналізує репозиторій, планує зміни та виконує їх
- ✅ **Робота з кодом** — створення, редагування, рефакторинг файлів
- ✅ **Виконання команд** — запуск тестів, збірки, dev-серверів
- ✅ **Підтримка різних LLM** — Anthropic, OpenAI, локальні моделі
- ✅ **Плагіни** — розширення функціоналу через `.opencode/plugins/` (наприклад, JS-плагіни)
- ✅ **Агенти** — кастомізовані конфігурації агентів через `.opencode/agents/`
- ✅ **Створений для команд** — підтримка спільної роботи через CLI

## 🎯 Переваги

- ⭐ **Безкоштовний та open-source** — MIT ліцензія
- 🚀 **Надзвичайно швидко зростає** — 200K+ зірок за ~1 рік
- 💻 **Працює в терміналі** — не прив'язаний до конкретного IDE
- 🔌 **Розширюваність** — плагіни та кастомні агенти
- 🌐 **Підтримка локальних моделей** — повний контроль над API
- ⚡ **Швидкий** — CLI-інтерфейс без зайвого GUI

---

## ⚠️ Недоліки

- ⚠️ **Молодий проєкт** — швидкий розвиток може ламати сумісність (5330 issues відкрито)
- ⚠️ **CLI-only** — немає вбудованого GUI/панелей IDE
- ⚠️ **Активна розробка** — API і конфігурації можуть змінюватися між версіями
- ⚠️ **Велике споживання контексту** — автономна робота потребує багато токенів
