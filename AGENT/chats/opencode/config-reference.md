# OpenCode — локальна довідка конфігурації

**Джерело:** `opencode.json` у корені репозиторію
**Призначення:** локальний опис конфігурації без переходу на зовнішній URL `$schema`.

## Поточний зміст

```json
{
  "$schema": "https://opencode.ai/config.json",
  "default_agent": "Comfy-smart-lady",
  "skills": {
    "paths": ["./AGENT/agents", "./AGENT/skills"]
  }
}
```

## Пояснення полів

| Поле | Значення | Призначення |
|------|----------|-------------|
| `$schema` | `https://opencode.ai/config.json` | Адреса JSON Schema для підказок і перевірки конфігурації редактором. Це не файл, який OpenCode завантажує як робочу конфігурацію. |
| `default_agent` | `Comfy-smart-lady` | Агент, який використовується за замовчуванням. |
| `skills.paths` | `./AGENT/agents`, `./AGENT/skills` | Шляхи пошуку агентів і навичок (префікс `./` — відносно кореня проєкту, безпечно для Windows і Linux). |

Плагіни в `opencode.json` не вказуються: OpenCode автоматично завантажує JS/TS-плагіни з каталогу `.opencode/plugins/` (стандарт opencode). Тож `anti-loop.js` та `startup.js` підхоплюються миттєво без `plugin`-масиву.

## Чому браузер або редактор пише «не надійний»

URL у `$schema` є зовнішнім посиланням для схеми JSON. Попередження про довіру означає, що поточне середовище не підтвердило або не може завантажити цю адресу. Воно не означає, що локальний `opencode.json` пошкоджений.

Для перегляду й пояснення конфігурації використовуйте цей локальний файл. Для роботи OpenCode основним залишається `opencode.json` у корені проєкту.

## Повна локальна схема

Оригінальну JSON Schema завантажено без скорочень у файл:

- `AGENT/chats/opencode/config-schema.json` — повний вміст `https://opencode.ai/config.json`.

Файл перевірено як валідний JSON. Він призначений для локального перегляду та резервної копії схеми.

## Що дали ці зміни

- Схему конфігурації можна переглядати без доступу до зовнішнього сайту.
- Повний опис параметрів збережено разом із репозиторієм і можна використовувати для довідки.
- Каталог агента показує локальну довідку поруч з описом OpenCode.
- Важливо: локальна копія ще не підключена до `$schema` у робочому `opencode.json`, тому зовнішнє попередження редактора поки може залишатися.
- Для повного переходу на локальну схему `$schema` має посилатися на `./AGENT/chats/opencode/config-schema.json`.

## Пов’язані файли

- `opencode.json` — робоча конфігурація OpenCode.
- `.opencode/agent-startup.md` — запускові інструкції.
- `.opencode/plugins/anti-loop.js` — локальний anti-loop плагін.
- `AGENT/chats/opencode/README.md` — опис OpenCode та інтеграції з агентом.
